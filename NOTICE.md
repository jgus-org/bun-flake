| Artifact                                                                                                                         | Licence & Notifications                                                                                                                                                                                                                                                |
| -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| This flake: its expressions, the launcher script, and `bun-restore-compiled-interpreter`                                         | [MIT](LICENSE.md)                                                                                                                                                                                                                                                      |
| [Bun](https://github.com/oven-sh/bun) at the release `pin.nix` selects, taken from upstream's `bun-linux-x64-baseline.zip` asset | [MIT for Bun itself, plus LGPL-2 for the statically linked JavaScriptCore and WebKit](https://github.com/oven-sh/bun/blob/bun-v1.4.4/LICENSE.md), whose own notice carries the relink condition quoted below; nixpkgs records the same asset as MIT and LGPL-2.1-only. |
| The copy the launcher writes on first use                                                                                        | Upstream's binary with its interpreter path rewritten to the loader Nix provides, and nothing else changed; it travels under the terms above.                                                                                                                          |
| `bash`, `coreutils`, `gnused`, `patchelf` and the rest of the launcher's closure                                                 | As the consumer's nixpkgs records each one in `meta.license`, where `free` and `redistributable` are separate properties                                                                                                                                               |

The asset is one file: unzipping it at the pinned hash yields `bun-linux-x64-baseline/bun` and nothing else, so upstream's notice does not travel inside what we distribute and is quoted here instead.

> Bun itself is MIT-licensed. Bun statically links JavaScriptCore (and WebKit) which is LGPL-2 licensed. WebCore files from WebKit are also licensed under LGPL2. Per LGPL2: (1) If you statically link against an LGPL'd library, you must also provide your application in an object (not necessarily source) format, so that a user has the opportunity to modify the library and relink the application. You can find the patched version of WebKit used by Bun here: <https://github.com/oven-sh/webkit>.

The unmodified asset stays in the store as the intermediate the launcher copies from, so a recipient always has upstream's own bytes at hand beside the rewritten copy. Both licences above are free and redistributable, so nothing here needs a consumer permit to build or run.
